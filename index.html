GituDoang Publisher

Upload tool for the GituDoang ID channel

GituDoang Publisher is a private tool used by the creator of GituDoang ID, a channel of short low-poly 3D explainer videos in Indonesian ("cara kerja" / how things work).

The tool uploads the channel's own finished videos, titles, descriptions and thumbnails to the creator's own YouTube channel using the YouTube Data API. It is not offered to the public and does not access anyone else's account.
