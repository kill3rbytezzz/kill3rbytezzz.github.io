Privacy Policy: GituDoang Publisher

Last updated: 22 November 2026

What the app is

GituDoang Publisher is a private desktop tool run by the creator of the GituDoang ID channel. It uploads the channel's own videos to the creator's own YouTube channel. It has a single user and is not available to the public.

Data accessed

The app uses YouTube API Services. With the account owner's consent (Google sign-in), it requests permission to upload videos and set thumbnails, and to read basic channel information (the channel name) to confirm it is signed in to the right channel. It does not read, collect or process data about any other user.

Storage and sharing

The Google sign-in token is stored only on the creator's own computer. No data is sent to any server other than Google's. No data is sold, shared with third parties, or used for advertising or analytics.

Revoking access

Access can be revoked at any time from Google Account permissions. Deleting the stored token on the computer removes the app's access as well.

Google and YouTube terms

By using this app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
